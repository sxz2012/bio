# Ecology study book for Shawn

The 66-page book covers teacher learning targets 1A–2C. It opens with a self-check and a seven-session study plan, then gives each target a vocabulary page, illustrated explanation pages, and a one-page summary sheet. The back of the book holds model answers to the teacher's study questions, review questions, a diagram review, an exam-format practice test, answer keys, and notes on the supplied practice key. A separate flashcard set is generated from the vocabulary pages.

- Editable LaTeX source: [ecology-1A-2C.tex](ecology-1A-2C.tex)
- Compiled PDF: [ecology-1A-2C.pdf](../../../output/pdf/ecology-1A-2C.pdf)

## Illustrations

Every concept diagram uses pictograms so that a ninth grader can read it at a glance. Icons come from Font Awesome Free 5 (`fontawesome5` package; icons CC BY 4.0). Organisms the icon set lacks (rabbit, mushroom, grass, soil, sun, road, coral) are small editable TikZ `pic` drawings defined in the preamble; reuse them with `\pic at (x,y) {rabbit=fur};`. Icon-and-label nodes use `\pn{color}{icon}{label}`. Eight teaching diagrams are drawn as scenes rather than flowcharts: the food web, energy pathway, gas exchange, feedback loops, ecological pyramid, biodiversity scales, habitat fragmentation, and the crowding loop. Two photographs were added in this revision (coral reef habitat and a pollinating honey bee); see [image credits](assets/CREDITS.md).

## Vocabulary pages

Each learning target opens with a one-page vocabulary table: the teacher's biology vocabulary with a meaning, an example or memory hook, and a page reference, followed by the target's academic vocabulary with a pointer to the two academic-vocabulary pages. Terms come from the [teacher guide](../teacher-guide.md); definitions are original study explanations.

## Study tools added in the September revision

- **Self-check and study plan** (front of the book): 24 "I can" statements mapped to the teacher's study questions, a seven-session plan, and a mistake log.
- **Summary sheets**: one page per target with key ideas, formulas, diagrams to redraw, and traps, for the night before an exam.
- **Teacher study questions, model answers**: every study question from the unit guide for 1A–2C answered in the required style (no "it," "thing," "normal," "natural," or "balance"), with page references. These are original study explanations, not teacher-issued answers.
- **Practice test A**: 15 multiple-choice items and one free-response item in the format of the StudyBio quiz, with a key that explains every distractor and a scoring guide for the free response.
- **CER template and rubric** (after the 2B argument page): fill-in template with sentence starters and a five-row rubric.
- **Flashcards**: 90 cards (64 biology terms across 1A–2C plus 26 academic-word rows). `python3 units/ecology/book/make_flashcards.py` reads the vocabulary pages of the main source and writes `ecology-flashcards.tex` and the TSV; the tex file is generated, so edit the vocabulary pages in the main book instead. Build the cards with the same Tectonic command, pointing at `ecology-flashcards.tex`. The TSV has an Anki header (tab separator, tags column); for Quizlet, paste the file with tab between term and definition and newline between cards.

## Rebuild

From the project root, using Tectonic:

```sh
tectonic --untrusted --outdir output/pdf units/ecology/book/ecology-1A-2C.tex
```

The first build downloads required TeX packages and fonts. For this session, Tectonic 0.17.0 is available at `tmp/tools/tectonic`; that temporary binary is not part of the book source.

With a TeX Live installation, run XeLaTeX twice from the project root:

```sh
xelatex -interaction=nonstopmode -halt-on-error -output-directory=output/pdf units/ecology/book/ecology-1A-2C.tex
xelatex -interaction=nonstopmode -halt-on-error -output-directory=output/pdf units/ecology/book/ecology-1A-2C.tex
```

Two passes resolve the contents and page references. Required packages are listed in the source preamble. Fonts are TeX Gyre Pagella and TeX Gyre Heros.

## Mind maps

Three topic mind maps follow the whole-unit knowledge graph: living systems (1A–1B), energy and matter (1C), and ecological change (2A–2C). Labeled branches with icons, dashed cross-branch links, cross-topic examples, common confusions, and redraw prompts support understanding and recall. All maps are editable TikZ. Keep hyphenation settings out of TikZ `font=` keys; use `execute at begin node` instead, or node text picks up stray glue text.
